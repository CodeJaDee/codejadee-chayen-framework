## Side effects to note

- **The Copilot CLI auto-updated itself from 1.0.91 to 1.0.97** in
  `%LOCALAPPDATA%\copilot\pkg` while the tests ran with auto-update enabled.
- **Codex.** The plugin was installed into the real `~/.codex` for routing
  tests (authentication is not portable to an isolated home), then removed
  with `codex plugin remove` and `codex plugin marketplace remove`.
  - `config.toml` is byte-identical to before.
  - Codex left an empty `plugins/cache/codejadee/` directory. It was removed
    with `rmdir`, and the cache listing is identical to before.
- **Claude Code `-p` runs** used `--no-session-persistence`. The `claude
  plugin eval` runs stored results only in the staged scratch copy.
